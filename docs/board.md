# ボードを操作する

最初に開くタスク画面は、現在のワークスペースのカードを「未着手」「設計中」「設計完了」「進行中」「レビュー中」「完了」「失敗・中止」の列に表示します。「失敗・中止」の列では、各カードに失敗かキャンセル済みかを表示します。左右キーで列、上下キーでカードを選択します。幅の狭いペインでは選択中の列を表示します。

| 操作 | キー |
| --- | --- |
| タスク・エージェント・自動化を順に切り替える | Tab（逆順は Shift+Tab） |
| 選んだ未着手カードを開始する／実行中の担当ペインを開く／終了後の結果を読む | Enter |
| 選択中のカードの詳細を開く | `v` |
| 新規カード・予定の作業内容入力中に担当を切り替える | `Ctrl+G` |
| 未着手の手動カード・自動化の予定の詳細で担当を切り替える | `g` |
| 未着手の手動カードの詳細で作業先を変更する | `p` |
| 開いているカードをキャンセルする | `x` |
| 設計や実装のレビューで修正コメントを入力する | `r` |
| 実装結果の承認を取り消す／キャンセルした手動カードを未着手に戻す | `u` |
| 定期実行カードの詳細で元の予定の間隔・時刻を変更する | `t` |
| 表示するプロジェクトを選ぶ・フォルダを追加する | `p` |
| 新しい手動カードの作業先を選び、作業内容を入力する | `n` |
| 操作方法とワークスペース一覧を見る | `?` |
| 入力や詳細表示から戻る | Esc |
| ボードを閉じる | `q` |

エージェント画面には同じ Herdr セッションの各ワークスペースで検出されたエージェントが並びます。現在のボードの担当ペインにはカード番号と作業内容が付きます。入力待ちは先頭に表示され、件数はタスク画面でも確認できます。上下キーで選び、Enter で担当ペインを開いてください。ワーカーやエージェントの状態は約2秒ごとに更新します。

## カードから作業を始める

ボードは「すべて」で開きます。`p` でプロジェクトを選ぶと、タスクと自動化の両タブがそのフォルダに絞られます。「すべて」に戻すと、全プロジェクトのカードをレーンごとに確認できます。プロジェクト名はフォルダ名で、同名のフォルダはカードにフルパスを表示します。既存カードと予定の作業先も選択肢に入ります。

旧版から更新するときは、実行中の作業が終わってから、ボードと稼働中のスケジューラーを新版で開き直してください。旧版がボードに書き込むと、新しく登録したフォルダの一覧が失われる場合があります。

- 新しいプロジェクトは `p` →「＋ フォルダを追加」で登録します。初回は直接フォルダ選択が開きます。↑↓ と Enter で移動し、「このフォルダを作業先にする」で確定します。
- タスク画面の `n` で、チケットの作業先を選んでから内容を入力します。たとえば API を表示中でも、Web を選んで Web のチケットを作れます。作成したカードは Web または「すべて」で確認できます。
- 入力中の画面上部に担当が表示されます。初期値は Codex です。`Ctrl+G` で Claude Code に切り替えてから登録すると、直接実行・設計・実装・再試行のすべてでその担当を使います。登録後も、未着手の手動カードなら詳細の `g` で変更できます。
- 未着手の手動カードは `v` で詳細を開き、`p` で作業先を選び直せます。設計や実装を始めると、その作業先で実行します。定期カードは予定に登録した作業先を引き継ぎます。
- 選択はボードのペインごとに独立しています。別ペインで選択を変えても、入力中の登録先や稼働中の定期実行には影響しません。エージェントタブではセッション全体を確認できます。

絶対パスが分かっている場合は、次のように直接入力することもできます。各行を Enter で確定してください。

```text
dir /absolute/path/to/project
add ログイン画面のテストを追加する
start 1
```

`dir` で指定した絶対パスはプロジェクトに登録され、このペインの表示先になります。`add` を確定すると、そのチケットの作業先を選ぶ画面が開きます。`start` にはボードに表示されたカード番号を指定します。専用タブでカード本文をプロンプトとして担当エージェントが起動し、カードが `In Progress` に移ります。

- `open 1` で実行中の担当ペインを開きます。
- 直接実行では終了コードが 0 なら `Done`、実行に失敗したら `Failed` になります。`result 1` で最終メッセージや起動エラーを表示します。
- 失敗したカードは `start 1` で再実行できます。ワーカーの強制終了で状態が残ったときは、担当エージェントの終了後に `recover 1` を実行してから再開します。更新前から動いていたワーカーでは、復旧前にエージェントの終了を確認してください。
- 作業を取りやめるときは、カードの詳細で `x` を押します。カードの状態は「キャンセル済み」になり、実行中ならワーカーが担当エージェントを停止します。担当ペインで `Ctrl+C` を押して中止した場合も「キャンセル済み」になります。途中までに加えたファイル変更は作業先に残ります。
- 「失敗」のカードも、詳細で `x` を押すと実行結果を残したまま同じ列で「キャンセル済み」に変更できます。定期実行のカードをキャンセルした場合、次回は予定どおり実行されます。
- `q` でボードを閉じます。カード、結果、定期実行の設定は Herdr のプラグイン状態ディレクトリにセッション・ワークスペース単位で保存します。

## 手動タスクを設計してから実装する

1. 「未着手」の手動カードを選び、`v` で詳細を開いて `d` を押します。担当エージェントが作業先を読み取り専用で調査し、変更方針・受け入れ条件・テスト方針・未決事項を設計案にまとめます。
2. 設計案が保存されると、カードは「設計完了」に移り、承認を待ちます。詳細は開いたまま自動更新されます。あとから「設計完了」のカードを選び、`Enter` で設計案を読めます。
3. 設計案を修正したいときは `r` でコメントを入力します。`Enter` で送信すると「設計中」に戻り、新しい案ができると再び「設計完了」に移ります。`Esc` で入力を取り消せます。
4. `a` で表示中の案を承認すると、元の依頼とその設計案を受け取った担当エージェントの新しい実行が実装とテストを担当します。実装中は「進行中」の列に表示されます。
5. 実装に成功すると「レビュー中」の列に移ります。カードを選び、`Enter` で詳細を開きます。設計案と実装結果を確認して `a` で承認すると「完了」に移ります。

### 差し戻しと再オープン

- **レビュー中 → 進行中**：詳細で `r` を押し、直してほしい点を書いて `Enter` を押します。担当エージェントが承認済みの設計案、前回の実装結果、修正コメントを受け取って実装を再開します。成功すると最新の結果で「レビュー中」に戻ります。`Esc` でコメント入力を取り消せます。
- **完了 → レビュー中**：実装結果を承認したカードの詳細で `u` を押すと、同じ設計案と実装結果を再確認できます。ここで `a` を押すと再承認、`r` を押すと修正依頼です。
- **キャンセル済み → 未着手**：手動カードの詳細で `u` を押すと、同じ番号・作業先で再オープンします。前回の設計案や結果は次の開始時まで詳細で確認できます。一覧の `Enter` で直接実行、詳細の `d` で設計から開始できます。

未着手カードで直接 `Enter` を押した作業と、定期実行のカードは、成功時にそのまま「完了」に移ります。設計や実装に失敗した場合は `start 番号` でそのフェーズを再試行できます。

毎日の時刻や実行間隔を設定する手順は、[定期実行](automation.md)を参照してください。
