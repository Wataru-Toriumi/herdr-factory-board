# ボードを操作する

ボードを開くと、タスクタブに現在のワークスペースの手動カードが並びます。未着手のカードは、一覧で `Enter` を押すと直接実行できます。先に設計案を確認したい場合は、`v` で詳細を開いて `d` を押します。

## カードから作業を始める

1. タスクタブで `n` を押して「新規タスク」を開き、「作業内容」を入力します。`Enter` で改行でき、複数行の貼り付けもできます。`Tab`・`Shift+Tab` で項目を移動します。
2. 作業先を確認します。初期値は表示中のプロジェクトです。「すべて」で候補が1件ならそのプロジェクトを使います。`Ctrl+P` または「作業先を選択」で、入力した本文を残したまま別のプロジェクトや新しいフォルダを選べます。
3. 必要に応じて `Ctrl+G` でこのカードの担当を切り替え、`Ctrl+S` または「保存」で未着手のカードを作成します。作業先が未選択なら選択画面が開きます。作業先を選んでから、もう一度保存してください。`Esc` で入力を取り消せます。
4. 一覧に戻り、左右キーで列、上下キーでカードを選びます。直接実行すると、担当エージェントが専用タブでカード本文を受け取って作業を始め、カードが「進行中」に移ります。実行中に `Enter` を押すと担当ペインを、終了後に押すと結果を開きます。

タスクタブの列は「未着手」「設計中」「設計完了」「進行中」「レビュー中」「完了」「失敗・中止」です。「失敗・中止」では各カードに失敗かキャンセル済みかを表示します。幅の狭いペインでは選択中の列を表示します。

### 作業先と既定の担当を選ぶ

一覧の `p` で表示するプロジェクトを選びます。初期表示の「すべて」では全プロジェクトのカードが列ごとに並びます。プロジェクトを選ぶと、このペインのタスクと自動化の両タブがそのフォルダに絞られます。別ペインの入力や稼働中の定期実行はそのまま続きます。

- **フォルダを登録する**には、`p` →「＋ フォルダを追加」を選びます。初回はフォルダ選択が直接開きます。↑↓ と `Enter` で移動し、「このフォルダを作業先にする」で確定します。既存のカードや予定の作業先も候補に含まれます。プロジェクト名にはフォルダ名を使い、同名ならカードにフルパスを表示します。
- **カードの作業先や担当を変える**には、未着手の手動カードを選び、`v` で詳細を開きます。`p` で作業先を、`g` で担当を変更できます。直接実行・設計・実装・再試行にはカードに保存した担当を使います。定期実行のカードは元の予定の作業先と担当を引き継ぎます。
- **新規タスク・予定の既定の担当を変える**には、一覧で `Ctrl+G` を押し、左右キーで Codex または Claude Code を選んで `Enter` で保存します。初期値は Codex です。設定はワークスペースごとに保存され、`add`、`daily`、`every` での新規登録にも使われます。

## 手動タスクを設計してから実装する

1. **設計を依頼する。** 未着手のカードの詳細で `d` を押します。カードは「設計中」に移り、担当が作業先を読み取り専用で調査します。設計案には変更方針、受け入れ条件、テスト方針、未決事項がまとまります。
2. **設計案を確認する。** 案が保存されると「設計完了」に移り、詳細が自動更新されます。あとから読むときはカードを選んで `Enter` を押します。修正するには `r` でコメントを書き、`Enter` で送信します。再設計中は「設計中」に戻り、新しい案ができると再び「設計完了」に移ります。`Esc` でコメント入力を取り消せます。
3. **実装を始める。** 詳細で `a` を押すと表示中の設計案が承認され、カードは「進行中」に移ります。担当エージェントが新しく起動し、元の依頼と承認済みの設計案に沿って実装とテストを進めます。
4. **実装結果を確認する。** 実装に成功すると「レビュー中」に移ります。`Enter` で設計案と実装結果を開き、`a` で承認すると「完了」に移ります。

直接実行と定期実行は、成功するとそのまま「完了」に移ります。設計や実装に失敗した場合は、`start 番号` でそのフェーズを再試行できます。

### 差し戻しと再オープン

| カードの状態 | 詳細での操作 | 操作後の状態と引き継ぐ内容 |
| --- | --- | --- |
| レビュー中 | `r` で修正点を書き、`Enter` で送信（`Esc` で取消） | 「進行中」に戻り、担当が承認済みの設計案、前回の実装結果、コメントを受け取ります。成功すると最新の結果で「レビュー中」に戻ります。 |
| 実装結果を承認して完了 | `u` で承認を取り消す | 「レビュー中」に戻ります。同じ設計案と実装結果を確認し、`a` で再承認、`r` で修正を依頼できます。 |
| キャンセル済みの手動カード | `u` で再オープン | 同じ番号・作業先で「未着手」に戻ります。次の開始時まで前回の設計案や結果を確認できます。一覧の `Enter` で直接実行、詳細の `d` で設計を開始できます。 |

## チケットで担当に相談する

手動カードの詳細で `c` を押すと、元の依頼・設計案・実行結果の下に会話が開きます。

1. 質問を書き、`Ctrl+S` または「送信」で担当に渡します。`Enter` で改行でき、macOS では `Ctrl+R` で音声入力もできます。
2. 担当は作業先を読み取り専用で調べ、元の依頼とこのチケットの会話を参照して回答します。相談中も現在の列で作業を続けられます。送信後にボードを閉じても回答は保存されます。
3. `PgUp`・`PgDn` で履歴を読み、`Esc` で詳細に戻ります。会話欄のボタンから設計の更新・実装修正・承認もできます。

会話をもとに修正を依頼するには、詳細で `f` を押します。「設計完了」なら再設計、「レビュー中」なら実装修正を依頼します。設計・実装・未着手からの直接実行では、開始時点で回答済みの会話も担当に渡ります。

## キャンセルと失敗時の復旧

- **作業を取りやめる**には、カードの詳細で `x` を押します。カードは「キャンセル済み」になり、実行中ならワーカーが担当エージェントを停止します。担当ペインの `Ctrl+C` でも中止できます。途中までに加えたファイル変更は作業先に残ります。
- **失敗した作業を取りやめる**場合も、詳細で `x` を押します。実行結果は保存され、「失敗・中止」の列で状態が「キャンセル済み」に変わります。定期実行のカードをキャンセルしても、次回は予定どおり実行されます。
- **ワーカーを強制終了して実行中の状態が残った**場合は、担当エージェントの終了を確認してから `recover 1` を実行し、作業を再開します。`1` は対象のカード番号です。旧版から動き続けている作業も同じ手順で復旧します。

## コマンドでカードを操作する

ボードで直接入力し、各行を `Enter` で確定します。

```text
dir /absolute/path/to/project
add ログイン画面のテストを追加する
start 1
```

`dir` は絶対パスをプロジェクトに登録し、このペインの表示先を切り替えます。`add` を確定したら、作業先の選択画面でこのカードのフォルダを選びます。次のコマンドの `1` には、ボードに表示されたカード番号を指定します。

| コマンド | 用途 |
| --- | --- |
| `start 1` | 未着手のカードを直接実行する。失敗したカードは再実行する。 |
| `open 1` | 実行中の担当ペインを開く。 |
| `result 1` | 最終メッセージや起動エラーを読む。直接実行は終了コードが 0 なら `Done`、失敗なら `Failed` になる。 |

## タブの移動とエージェントの確認

`Tab` で「タスク」→「エージェント」→「レビュー」→「自動化」の順に移動し、`Shift+Tab` で逆順に戻ります。

- **エージェント**には、同じ Herdr セッションの全ワークスペースで検出したエージェントが並びます。現在のボードの担当ペインにはカード番号と作業内容が表示されます。上下キーで選び、`Enter` でペインを開きます。入力待ちは先頭に並び、件数はタスクタブでも確認できます。状態は約2秒ごとに更新されます。
- **レビュー**には、GitHub CLI（`gh`）でログイン中のアカウントにレビュー依頼があるオープンな PR が並びます。初回は `gh auth login` で認証してください。タブを開くたびに、GitHub からリポジトリをまたいで更新順に最大1,000件取得します。上下キーで PR を選び、`d` で差分を表示します。上下左右キーでスクロールし、`PgUp`・`PgDn` でページを移動します。`Esc` で一覧に戻ります。一覧の `Enter` でブラウザにも開けます。`r` で再取得できます。
- **自動化**では `h` で予定と実行履歴を切り替えます。登録や編集の手順は[定期実行](automation.md)にまとめています。

一覧の `?` で操作方法とワークスペース一覧を確認できます。`q` でボードを閉じます。カード、結果、定期実行の設定は Herdr のプラグイン状態ディレクトリにセッション・ワークスペース単位で保存されます。旧版を使っている場合は、先に[更新手順](getting-started.md#旧版から更新する)を確認してください。

## フォームで音声入力する（macOS）

新規タスクの「作業内容」、自動化の登録・編集フォームの「実行内容」、手動カードの会話で使えます。

1. 本文の挿入位置を決め、`Ctrl+R` または「音声入力」を選びます。初回はマイクと音声認識へのアクセスを許可してください。
2. 「録音中」と表示されたら日本語で話し、`Ctrl+R` または「停止」を選びます。文字起こしは挿入位置に入り、選択中の文字があれば置き換えます。`Esc` または「取消」で録音・文字起こしを取り消せます。
3. 本文を確認・編集し、`Ctrl+S` でフォームを保存します。会話欄では同じキーで送信します。

音声入力にはボードを実行している Mac のマイクと、日本語のオンデバイス音声認識を使います。日本語を認識できない場合は「システム設定 → キーボード → 音声入力」で言語を確認してください。Linux ではキーボード入力と貼り付けを利用できます。
